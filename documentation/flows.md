# Flows across trust boundaries

| Flow | Actor and precondition | Steps, checks and side effects | Expected refusal |
| --- | --- | --- | --- |
| Publish | Repository maintainer with write access; reviewed PR | GitHub accepts commit/merge after maintainer checks CI. Cloudflare's existing app observes `main`, builds/tests, then deploys through its stored credential. Public content changes only after deploy succeeds. | Read-only GitHub users cannot update the repository. Cloudflare rejects unauthorized deployments; build/test failure must stop deployment. |
| Archive | Maintainer publishes a versioned GitHub release | GitHub Actions checks out its tag, builds/tests, checks tag/package/commit/clean state, hashes compiled files, and attaches backup using the job's repository-scoped token. This workflow does not deploy. | Mismatched tag, dirty checkout or failed tests abort archival. The token is not bundled into the artifact. |
| Public fetch | Any visitor or bot | Browser requests page; Worker canonicalizes HTTPS/www and legacy aliases, checks document route, returns public HTML/text or delegates media to ASSETS. No writes or private data reads. | Unknown document returns 404; document methods other than GET/HEAD return 405. |
| Notebook import/export | Visitor deliberately uses HuddleDex browser demo | UI reads selected file, parses local records, persists them in that browser's IndexedDB, or downloads an export. No data goes to Tyler's server. | Invalid imports must fail visibly. Storage failures do not imply a successful save. These cases need manual review; see tests.md. |
| Outbound AI/email links | Visitor activates link or copy button | Public prompt is copied only on interaction; AI links open the chosen provider for the visitor to paste. Email uses `mailto:`. | The website does not send email or submit prompts automatically. Provider accounts and actions remain outside this site. |
| Emergency rollback | Authorized Cloudflare operator | Restore a retained version or verified release archive, verify live, then reconcile GitHub through a rollback PR. | Do not claim a rollback succeeded based only on a command exit; verify the restored content. |
